This dataset includes Taillard's instances and a set of instances I generated.
All instances have the same format as Taillard's.

Taillard's instances and the related information are available also at http://mistic.heig-vd.ch/taillard/problemes.dir/ordonnancement.dir/ordonnancement.html

Let p_ij be the processing time of job j on machine i.
Let n be the number of jobs and m be the number of machines.

Each file contains:
nr_of_jobs nr_of_machines seed upper_bound lower_bound
p_11 ... p_1n
p_21 ... p_2n
 .   ...  .
 .   ...  .
 .   ...  .
p_m1 ... p_mn

Note: for the instances I generated, the values of upper_bound and lower_bound in the file are dummy values.
